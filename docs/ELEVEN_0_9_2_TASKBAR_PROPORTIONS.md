# Eleven 0.9.2: taskbar proportions

The owner’s portrait screenshot showed Search and Task View much smaller than pinned app icons, with tighter fixed-control spacing followed by broad app-button spacing. This pass uses a common 24dp icon canvas (20dp below 360dp), normalizes the line artwork’s optical bounds only on the taskbar, and gives fixed/pinned/running icon buttons a consistent 32dp pitch on ordinary portrait phones and 40dp on wider layouts. Extremely narrow fixed controls retain their compact width while app targets remain at least 32dp. Labeled tasks retain their wider layout and static-fit behavior.

The N¹¹ mark preserves the existing vector artwork and aligns its visible badge to the same icon scale. Search, Task View and Nota retain their commands, long-press behavior and keyboard focus. Widgets is centered in its compact cell. Pixel-sized portrait layouts give the clock a 72dp cell with up to 11sp text, while narrower phones retain their bounded compact clock. System tray, clock, 24dp Show desktop target and Android navigation remain separate. Expansion keeps the same fixed controls and bounds, running apps above and idle pins below, without rewriting desktop positions.

Regression coverage includes actual rendered icon bounds, centered icon artwork, common fixed/pinned spacing, real restore touches at 320/360/411dp, both alignments, both battery preference values, light/dark collapsed/expanded screenshot captures, the existing taskbar frame stability checks, full native Eleven/shared-engine regression, separate Usage Access recovery, and upgrade from 0.9.1. Native driver assertions continue to exercise user input rather than calling restore directly.

Version 0.9.2/code15 preserves Eleven’s application ID, original preview signing identity, setup state and backup formats. Captured test results and source/signing metadata accompany the delivered build.
