# Preview signing continuity

The downloadable Eleven preview uses a retained, owner-controlled preview key. The public repository does not contain that key. GitHub Actions APKs use disposable runner debug keys; re-sign a tested build with the retained key before distributing a new preview update.

Retained file: `Nth-Desktop-Eleven-Preview-Signing.jks` in the owner's project files. It is stored separately from the APK/download ZIP. This is the standard Android preview keystore format, alias `androiddebugkey`, store/key password `android`.

Expected signer certificate SHA-256:

`b704c7a2da2d0d4425fa5fe61c122483389b07be327ad565ff198064af696265`

Use Android Build Tools `apksigner` to sign the tested APK with this key, then run `apksigner verify --print-certs`. Increase the version code for later updates. Compare the distributed APK's classes/resources/assets with the tested CI package after signing; only signing metadata should change.

The first key was generated by the Android debug build tools and retained for preview update continuity. Do not place it in this public repository or bundle it in the install ZIP.
